Where the games come from

    
JS ScummVM plays games from a webЯcade feed: a JSON file listing games,
      each with a link to a zip of its files. Give it one as ?feed=
      in the address, or paste its address when asked; the last one is
      remembered.

    
    
      
  • Which games. Every item of type scumm. Feed
        items have no id, so each is told by its title or its zip's file name
        against ScummVM's names for its games — “The Secret of
        Monkey Island”, “Monkey Island”,
        Monkey-Island-CD-DOS.zip — and gets a folder in
        C:\GAMES named by ScummVM's id for it
        (MONKEY, DIG, ATLANTIS…),
        holding the zip's files and an .EXE to run it. For now
        The Secret of Monkey Island and Monkey Island 2 run, and Indiana
        Jones and the Fate of Atlantis is on its way.
    • 
      
  • The zip. The game's two data files, MONKEY.000 and
        MONKEY.001 (or MONKEY1.000 and
        .001), in any folder; and for the music, the CD tracks as
        track1 to track24 in WebM, Ogg, MP3, FLAC
        (.flac or .fla) or WAV. A talkie's speech is
        MONSTER.SOU, or ScummVM's compressed
        .SOF (FLAC), .SOG or .SO3.
    • 
      
  • Hosting. The feed and the zip must let other sites read them
        (CORS). Dropbox share links work; archive.org's do not.
    • 
      
  • Downloading. Only the files the game needs are taken out of the
        zip, when it needs them, and kept in the browser for next time. The
        speech is the exception: it comes whole, before the game starts.
    • 
    

    
Then at the C:\> prompt type cd games\monkey
      and monkey. The power button switches the monitor off and
      on.
